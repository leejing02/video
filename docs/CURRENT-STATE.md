## 2026-11-07 游客身份（未提交）

- 不再强制注册：未登录时前端自动调用 `POST /api/guest`，取得游客身份后直接使用（聊天、点赞、评论等与普通用户相同）。
- 按设备区分：浏览器/手机本地保存随机设备 ID（`localStorage.guest_device`，30 天后更换）；服务端用 `HMAC(JWT_SECRET, 设备ID)` 派生账号，同一设备拿回同一身份。游客是 `users` 表普通记录（邮箱 `guest-<key>@guest.invalid`、用户名 `guest_<key>`、昵称「游客XXXX」、不可用密码登录），**无需数据库迁移**。
- 有效期一个月：游客 token 到「账号创建 + 30 天」过期；过期后同设备再次请求时旧账号停用（邮箱改为 `guest-expired-<id>@guest.invalid`）并发新身份。token 失效时游客自动续上，正式账号仍回登录页。
- 「我」页面游客显示「游客身份，有效期至…」和「登录 / 注册账号」；游客可进入登录页登录或注册正式账号（注册拒绝 `@guest.invalid` 邮箱和 `guest_` 开头用户名）。
