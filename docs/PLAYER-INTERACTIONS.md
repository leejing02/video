# 播放页交互改版

- 保留独立 iPhone 黑色 HTML、黑色顶部配置、封面启动交接和原尺寸逻辑。没有添加黑色标题条。
- 右侧作者头像、点赞、评论、收藏和分享采用白色图形及独立计数。
- 点头像或作者名称打开作者面板，展示已知作者资料和当前视频队列中的作者作品；关注为页面预览，未连接关注服务。
- 分享面板支持系统分享、复制可访问的播放链接。私信、微信、QQ、海报、举报等为页面预览，明确标注暂未开放，不声称已发送或已举报。
- 评论面板支持根评论分页，任何回复均可继续回复。每一级通过 parent_id 单独分页加载，视觉缩进在两层后固定，数据层级不受两层限制。
- 创建回复校验父评论属于当前视频。评论接口不缓存，不会把其他视频的回复混入。
- 暂不接入评论点赞、地理位置、语音和图片评论；不展示虚构的点赞或地址数据。
- 本次需要同时部署 api 和 web，无数据库结构变更。


## 播放页底部与最新评论

- 作者、作品文案和最新评论预览排列在底部黑色区域，顶部黑色页面设置、媒体尺寸与返回手势不变。
- 预览显示最新一条顶层评论的头像、昵称与内容；点击预览、右侧评论按钮或底部圆角评论入口，均打开完整评论面板，继续分页查看历史评论及多级回复。
- 预览随当前视频切换、回到前台及每 15 秒的互动刷新更新；新评论发送成功后重新读取。请求结果校验视频及请求版本，避免切换时串入旧视频内容。
- 没有评论时不渲染空预览。语音、图片输入未接入，不展示不可用按钮。
- 此次底部布局仅需重新构建 web。
