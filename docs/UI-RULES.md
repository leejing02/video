# 不可回退的 UI 与交互规则

修改任何功能前先读本文件。与本文件冲突的修改，必须先得到用户确认。
来源：用户确认的需求（REQUIREMENTS-2026-11-05.md）、CLAUDE.md、已验收的提交。

## 播放页（最高优先级）

- 播放页顶部（含 iPhone 状态栏区域）为纯黑 `#000000`；普通页面为白色。顺序：白 → 播放时黑 → 返回后白。
- iPhone 使用独立黑色文档 `web/player.html`；其他设备使用站内覆盖层。
- `player.html` 顶部的 `#playback-status-tint` 黑色细条不得删除：iOS 26 Safari 不看 `theme-color`，靠顶边不透明固定元素取色（提交 `a21c51b`）。
- 返回按钮 `.player-close` 必须保留：左上 `12px / max(12px, 安全区)`，44×44，半透明圆底 `#0006`，白色「‹」；不加橙色焦点圈（`490bd7d`）。
- 返回按钮叠在视频上，不为它另加黑色标题条或占位。
- 不得通过修改全局 `body`、`header`、`nav` 样式影响播放页；不得无故重构播放页 DOM。
- 点返回 / 右滑返回：列表垫在下面、暗色遮罩渐亮、视频缩回所在卡片，无黑屏白屏（`ea6da5f`，参考 `cankao/IMG_3420.MP4`）。
- 进入播放页先显示所点封面，首帧就绪后交接，不闪蓝屏/黑屏。

## 手势

- 只保留两种横向交互：聊天详情右滑返回会话列表、短视频左右滑动切换小分类。
- 聊天详情右滑返回已验收，**不要为拦截其他页面而改它**。

## 列表与封面

- 双列瀑布流：列宽固定，封面高度按图片原比例，不裁切、不加固定比例灰框（`f1cdc63`）。
- 卡片之间保留细小间隙，分类切换动画中也不能消失。
- 首页封面使用转码后台（EFV）的封面，经图片域名加载并解密（`ba9e15f`）。

## 导航与布局

- 底部主导航：群聊｜短视频｜＋｜长视频｜我；聊天详情和播放器内隐藏。
- 前台不显示直播入口，不开放用户自建群。

## 验收要求

- 修改前记录播放页顶部样式与结构；修改后确认顶部仍为 `#000000`、返回按钮存在且可用。
- iPhone 状态栏颜色、返回动画必须在 iOS 26 Safari 真机确认；无法确认时报告「未验证」，不得宣称完成。
