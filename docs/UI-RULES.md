# 不可回退的 UI 与交互规则

修改任何功能前先读本文件。与本文件冲突的修改，必须先得到用户确认。
来源：用户确认的需求（REQUIREMENTS-2026-11-05.md）、CLAUDE.md、已验收的提交。

## 播放页（最高优先级）

- 播放页顶部（含 iPhone 状态栏区域）为纯黑 `#000000`；普通页面为白色。顺序：白 → 播放时黑 → 返回后白。
- iPhone 使用独立黑色文档 `web/player.html`；其他设备使用站内覆盖层。
- `player.html` 顶部的 `#playback-status-tint` 黑色细条不得删除：iOS 26 Safari 不看 `theme-color`，靠顶边不透明固定元素取色（提交 `a21c51b`）。
- 返回按钮 `.player-close` 必须保留：左上 `12px / max(12px, 安全区)`，44×44，半透明圆底 `#0006`，白色「‹」；不加橙色焦点圈（`490bd7d`）。
- 返回按钮叠在视频上，不为它另加黑色标题条或占位。
- 不得通过修改全局 `body`、`header`、`nav` 样式影响播放页；不得无故重构播放页 DOM。
- 点返回 / 右滑返回：列表垫在下面、暗色遮罩渐亮、视频缩回所在卡片，无黑屏白屏（`ea6da5f`，参考 `cankao/IMG_3420.MP4`）。
- 进入播放页先显示所点封面，首帧就绪后交接，不闪蓝屏/黑屏。

## 手势

- 只保留两种横向交互：聊天详情右滑返回会话列表、短视频左右滑动切换小分类。
- 聊天详情右滑返回已验收，**不要为拦截其他页面而改它**。

## 列表与封面

- 双列瀑布流：列宽固定，封面高度按图片原比例，不裁切、不加固定比例灰框（`f1cdc63`）。适用于短视频列表；长视频列表按下方「长视频 V1」的固定 2:3 卡片（用户 2026-11-08 确认）。
- 卡片之间保留细小间隙，分类切换动画中也不能消失。
- 封面使用转码后台（EFV）的**封面1**，图片保持加密：后台同步时把封面1 地址写入数据库 `videos.cover_source`，Go 接口按数据库地址 + 当前 `image_origin` 返回，浏览器加载加密图片并解密显示；本站副本 `cover` 用于后台预览和加载失败时备用。不在请求时临时推算或向 EFV 查询封面地址（用户 2026-11-07 确认）。
- 不得用 EFV 采集接口的 `vod_pic` 预览小图（如 450×230）替代封面1。

## 导航与布局

- 底部主导航：分类｜推荐｜＋｜群聊｜我；聊天详情和播放器内隐藏（用户 2026-11-08 确认）。
  - 分类 → `/long` 长视频分类首页（分类列表为 `/long/category/:id`）；推荐 → `/short` 短视频列表及原播放器；＋ → `/upload` 发布；群聊 → `/chat`；我 → `/me`。
- 前台不显示直播入口，不开放用户自建群。

## 长视频 V1（已验收冻结）

用户 2026-11-08 视觉验收通过（功能提交 `6005351`）。以下布局不得改回，变更须先得到用户确认。

**分类首页 `/long`**
- 双列 16:9 分类封面（分类自己的封面，不用视频封面；没有封面时为灰色底）。
- 顶部标题「长视频」水平居中；第一版不显示左上角菜单按钮。
- 分类名称在封面下方，18px、600 字重、水平居中；长名称允许换行，不截断。
- 同一排的封面顶部对齐（名称换行不影响旁边卡片）。

**分类列表 `/long/category/:id`**
- 不显示「全部 / 影视剧 / 纪录片 / 教育」等顶部分类标签，也不能横向滑动切换分类；只显示进入时的分类。
- 左上角保留返回按钮，遵循浏览器历史返回上一页（直接打开时回到 `/long`）；顶部标题固定「长视频」，保留搜索。
- 双列竖版 2:3 卡片：横向间距 4px、纵向间距 6px；封面 `object-fit: cover`；同一行卡片等高、封面顶部对齐。
- 缺失或加载失败的封面为纯灰色占位（`#e9e9e9`），不显示图标或文字；右下角时长角标保留。
- 卡片只显示封面、标题、时长，不显示作者、点赞。
- 空状态：「暂无视频 / 该分类暂时没有视频」，不加切换分类按钮。
- 从详情页返回列表时，恢复原来的视频数据和滚动位置。

**详情与播放器 `/video/:id`**
- 不显示简介、作者、点赞、收藏、分享、评论和评论输入框；保留标题、播放量、发布日期。
- 「更多推荐」保持横向滚动小卡片布局（同分类其他视频），没有时显示「暂无推荐」。
- 普通播放使用自定义控制条（播放/暂停、时间、进度、倍速、全屏），视频 16:9 区域 `contain`、不裁切。
- iPhone 全屏使用系统原生全屏（iOS 控制条），不在其上覆盖网页控制条，不做伪全屏。
- Android 使用自定义页面元素全屏（标题、分享、底部控制条），并尝试锁定横屏；全屏时隐藏底部导航。
- 第一版不提供锁屏、选集、手动清晰度切换。

**不影响**
- 短视频播放器（`ShortVideoPlayer.vue`、`player.html`）和推荐页 `/short` 的规则不变，包括推荐页的分类标签、瀑布流和空状态文案。

## 验收要求

- 修改前记录播放页顶部样式与结构；修改后确认顶部仍为 `#000000`、返回按钮存在且可用。
- iPhone 状态栏颜色、返回动画必须在 iOS 26 Safari 真机确认；无法确认时报告「未验证」，不得宣称完成。
