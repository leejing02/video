# 已确认的视频与聊天改版

用户于 2026-11-02 确认 CAPABILITIES-social-ui.md 的范围并要求实施。

## app-shell
四个底部入口：群聊、短视频、长视频、我的。黑底、橙红强调色、线形图标。直播前台路由重定向短视频。固定动态视口，仅内容滚动，手机缩放手势受限；桌面菜单缩放不强制阻止。

## conversations
GET /api/chat/rooms 返回可加入的后台群组以及本人的私聊，附最后消息、未读数、成员数。POST /api/chat/direct 接收 user_id 和 context_room_id，只能从可访问群中的成员/发言者发起私聊；事务内按唯一的双方 slug 复用房间并写入双方成员关系。禁止向停用房间访问、私聊越权和自聊。不增加用户公开搜索接口，不变更已有数据库结构。

## realtime-chat
单个鉴权 WebSocket room_id=0 接收本人可访问会话的新消息通知。只有全局群向所有已连接用户推送，其他房间按当前成员列表推送。历史使用 before_id 分页；断线重连使用 after_id 正序分页补消息。客户端按消息 ID 去重、按房间存储，异步操作绑定房间 ID 防止切群混入。发送失败保留草稿。未读数使用服务端 last_read_at，列表定时刷新发现新私聊，消息实时推送。

## 实施顺序与检查
1. API/仓储/权限测试和 WebSocket 事件。
2. 前端会话视图、消息输入和状态管理、导航与视口。
3. Go 全量测试与 vet；Vue 类型检查与构建；浏览器移动/桌面场景与两会话收发。

部署：更新 api、web 镜像，后台不用重建；运行中的线上服务器不在本机工具控制内。
