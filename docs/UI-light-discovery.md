# 浅色视频发现页

以用户提供的快手发现页截图为视觉参考，不复制品牌、头像、封面或未实现的商城、关注、同城入口。

- 色彩：白色 #ffffff、列表底色 #f5f5f5、主文字 #191919、辅助文字 #707070、分隔线 #ededed、发布强调色 #ff315b。中文使用系统字体。
- 短视频：手机双列、3:5 封面、紧凑作者与点赞数；点击打开原有短视频播放器，上下切换、点赞、收藏、评论与分享继续保留。返回后保留列表位置和筛选。
- 长视频：双列横向封面，展示标题、作者、时长与点赞；点击进入详情。
- 电脑：700px 起三列，1100px 起四列，最大内容宽度 1440px。
- 分类使用文字标签，选中项加粗；搜索过滤当前已加载视频的标题与作者。分页仍通过加载更多获取。
- 底部采用五项布局：首页（短视频）、精选（长视频）、中央圆形加号（现有发布页）、消息（聊天）、我（个人页）；会话和短视频播放器内不渲染主导航。聊天仍采用既定 Telegram 会话布局。
- 登录、个人资料、上传说明、详情及个人页下的辅助页面采用浅色界面。游戏和实际视频画面保留自身配色。
- 使用真实接口数据，缺封面显示占位，缺数据、请求失败、加载中分别给出对应状态。不在生产代码中填充示例视频。
- 网页无法承诺隐藏 iOS 系统状态栏及 Safari 输入辅助栏；全局 HTML 与初始背景统一浅色。

验证：类型检查、前端构建、现有聊天回归测试；通过本地模拟接口检查分类、搜索、列表与播放器、详情、个人页、会话导航以及多尺寸布局。真机 Safari 的系统区域需另行实测。

底部参考图中的未读数字与红点不使用虚构数据；当前不添加无数据来源的提示标记。
