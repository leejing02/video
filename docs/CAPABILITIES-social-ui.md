# 视频与聊天改版能力图（用户已确认实施）

| 模块 | 职责 | 依赖 |
| --- | --- | --- |
| app-shell | 快手式深色、橙红强调色、固定视口、页面内部滚动；移除直播前台入口和前台路由；保留群聊、短视频、长视频、我的 | 现有登录与路由 |
| conversations | 列出可访问群聊和私聊；从群成员发起私聊；同一对用户重复发起复用会话；仅双方可读写私聊 | 现有用户、房间、成员表 |
| realtime-chat | Telegram 式会话列表和气泡；手机列表/详情切换、桌面双栏；分页历史、去重、切换防串消息、断线重连后补消息、未读提示 | conversations、现有 WebSocket |

构建顺序：app-shell → conversations → realtime-chat → 联调与浏览器验证。

## 默认范围

- 本次仅改 Vue 用户网站和 Go API，后台与原生 iOS 不改版。
- 群由管理员在现有后台维护；前台可查看并切换公开群及已加入群。
- 私聊从群消息发送者/群成员入口发起，不公开邮箱、手机号，不新增公开用户目录。
- 实时消息落库，支持刷新恢复、发送与推送去重、重连同步；无端到端加密承诺。
- 移除直播指隐藏前台入口并阻止前台直播页访问，保留历史数据和后台管理。
- 固定页面视口，允许内容区域纵向滚动，输入字号至少 16px，限制移动端双击/双指缩放；桌面浏览器菜单缩放不承诺强制阻止。
- 不包含语音通话、文件上传、用户自建群、邀请审批、屏蔽举报、跨实例消息总线。

## 验收方向

- 四个底部入口可用，没有直播入口。
- 群切换及连续快速切换不混入其他房间消息；加载历史保持位置。
- 两个账号可互发私聊；第三个账号不能读取、加入或发送到该私聊。
- 两个浏览器会话无需刷新即可收发消息；重连后补回断线期间的消息。
- 手机横竖屏、键盘弹起时主页面不溢出，消息输入框可见。
- 使用真实 Go 测试、前端类型检查、构建及浏览器场景验证；线上部署另行执行。
